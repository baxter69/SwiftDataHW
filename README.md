Домашнее задание
- Реализация поддержки оффлайн режима в приложении

Цель:
- реализовать оффлайн режим в приложении.

Описание/Пошаговая инструкция выполнения домашнего задания:
- Создать приложение, которое получает данные из сети:

Реализовать кэширование данных с использованием одной из технологий: Realm, Files, Firebase, CoreData (предпочтительно использовать новую для вас технологию).
- Убедиться, что модели данных поддерживают протокол Codable.
- Либо реализовать кэширование другим способом: UserDefaults, NoSQL (CouchDBLite, PinCache), Keychain, SwiftData.
- Реализовать сохранение данных в файл при выходе с экрана тестирования структуры данных.
- Загружать сохраненные данные при запуске приложения или повторном входе в экран тестирования.
- Должно сохраняться состояние предыдущего тестирования даже после перезапуска приложения.

--------------------------------------------------------------------------

 Как проверить оффлайн-режим
- Запустить приложение.
- Добавить несколько сообщений.
- Закрыть приложение (свайп вверх).
- Перезапустить — сообщения останутся.
- Отключить Wi-Fi / интернет — приложение всё равно работает, потому что данные локальные.
